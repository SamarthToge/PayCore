# PayCore

PayCore is a two-phase fintech learning project.

## Phase 1
Personal Finance Tracker

## Phase 2
Closed-Loop Digital Wallet with Razorpay test-mode top-up, internal transfers, double-entry ledger, idempotency, locking, Redis rate limiting, and admin reconciliation.

## Tech Stack
Spring Boot, React.js, MySQL, JWT, Razorpay Test Mode, Redis, Docker, GitHub Actions
