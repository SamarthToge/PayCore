# PayCore

PayCore is a two-phase fintech learning project.

## Phase 1
Personal Finance Tracker
- User registration/login
- Accounts
- Categories
- Manual income/expense transactions
- Dashboard and reports

## Phase 2
Closed-Loop Digital Wallet
- Razorpay test-mode wallet top-up
- Internal user-to-user transfers
- Double-entry ledger
- Idempotency keys
- Optimistic/pessimistic locking
- Admin reconciliation
- Redis rate limiting
- Notifications

## Tech Stack
- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- React.js
- Tailwind CSS
- JWT
- Razorpay Test Mode
- Redis
- Docker
- GitHub Actions
